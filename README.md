# VELTHON Write — website frontend

Public static frontend for GitHub Pages. Release 1.0.5.

Live app: https://hafarouk.github.io/Velthon-Write-Web/

Workspace sign-in is verified by the existing VELTHON authentication server and remains limited to the existing Emma, George and Hany accounts. No public registration. No passwords, authentication verifiers, server configuration, user notes, backups or logs belong in this repository. The original complete source repository remains private.

## Writing focus

Press the four-square icon at the upper left to collapse the header, notebook list, title and footer. Drawing tools and utility icons remain on the page edges, with a small page-navigation dock. Press the same icon again to restore the workspace. Escape closes the current dialog/menu first, or exits focus if no overlay is open.

## Your notes

Notes and saved scan photos are encrypted on the current browser/device. GitHub Pages hosts the website; the existing VELTHON service verifies sign-in. The password is unchanged.

Browser storage belongs to its website address. To move notes from https://velthon-student-hub-trial.velthonhome.chatgpt.site/write/, export an encrypted backup there, then sign in and restore it at the new GitHub address. Check your restored notes before clearing the old browser data.

## Publication

GitHub Pages publishes main/root using .nojekyll. All app and service-worker paths are relative. Existing font/icon licences are included. Never upload backend code, credentials or user data here.
